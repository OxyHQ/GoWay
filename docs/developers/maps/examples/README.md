# Maps SDK examples

Each example is a complete component you can paste into an app set up as in [the overview](../README.md#set-up). They run unchanged on the web, iOS and Android unless the page says otherwise.

| Example | Shows |
| --- | --- |
| [Display a map](display-a-map.md) | a `MapView` with an opening view, in your theme |
| [Markers and clusters](markers-and-clusters.md) | `Markers` with clustering, selection and a detail card |
| [Fit the map to data](fit-bounds.md) | framing a result set with `camera`, and a "back" button with the ref |
| [Search this area](search-this-area.md) | arming a button only on the reader's own moves |
| [Draw a route](draw-a-route.md) | `client.routes.directions` drawn with `GeoJSONSource` and `Layer` |
| [Locate me](locate-me.md) | `UserLocation`, `useUserLocation` and `useMap` |
| [Custom markers](custom-markers.md) | `renderMarker` branching on `kind` |
| [Pick a place on the map](pick-a-place.md) | `onPress` with basemap labels, reverse geocoding the rest |
| [Style switcher](style-switcher.md) | GoWay styles and pinned lights |
| [Labels on screen](labels-on-screen.md) | `onLabelsChange` as a list beside the map |
