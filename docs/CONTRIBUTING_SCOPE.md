# Initial implementation scope

The first release should prioritize:

- map rendering
- place discovery
- reusable SDK primitives
- Oxy Places enrichment
- directions/routing
- FairCoin merchant discovery example

Explicitly defer:

- Street View / street-level imagery
- traffic prediction
- transit network ingestion at global scale
- full self-hosting of world vector tiles
- copying the full OpenStreetMap planet into the GoWay application database
