# Oxy Maps SDK vision

The SDK should let any Oxy or third-party app consume maps and places without depending directly on MapLibre or any map data provider.

Target package: `@oxy.so/maps`

Core areas:

- Map rendering primitives
- Markers and annotations
- Camera / viewport control
- Places search and place details
- Directions and route geometry
- Layer composition
- Provider adapters
- Shared TypeScript types

Example consumers include GoWay, FairCoin Wallet, Moovo, Mercaria, Homiio, Mention and Clarity.
