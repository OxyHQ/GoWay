# GoWay Initial Roadmap

The first implementation phase focuses on a production-quality map foundation, reusable SDK, Oxy Places, search, routing and ecosystem integration. Street-level imagery is not part of the initial scope.

Planned tracks:

- Expo app foundation
- MapLibre rendering with OpenFreeMap
- `@oxy.so/maps` SDK
- Oxy Places + PostGIS
- Search and geocoding
- Routing and directions
- GoWay map UX and Bloom visual language
- FairCoin merchant discovery integration
- Provider abstraction, caching and resilience
