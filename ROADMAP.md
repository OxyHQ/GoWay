# GoWay Initial Roadmap

The first implementation phase focuses on a production-quality map foundation, the reusable `@goway.to/sdk`, the GoWay Places schema, search, routing and ecosystem integration. Street-level imagery is not part of the initial scope.

Planned tracks:

- Expo app foundation using the Oxy `packages/*` convention
- MapLibre rendering with OpenFreeMap
- `@goway.to/sdk`
- GoWay Places schema + PostgreSQL/PostGIS migrations
- stable Place IDs, source provenance and business/capability relationships
- Search and geocoding
- Routing and directions
- GoWay map UX and Bloom visual language
- FairCoin merchant discovery integration
- Provider abstraction, caching and resilience
